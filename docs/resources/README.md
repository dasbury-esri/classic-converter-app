# Resources

Methodology, reference material, and external links for this project.

## What belongs here

- Reference material and best practices
- External links and methodology docs
- Anything that informs how the project is built or used

## What doesn't belong here

- Decisions (those go in `docs/decisions/` as ADRs)
- Current state (that goes in `STATUS.md`)
- Session logs (those go in `session-logs/`)
- Reusable templates (those go in `docs/templates/`, if the project needs any)

Reference paths repo-relative, not by their location on one machine
(see `CONVENTIONS.md` → OS-agnostic paths).
